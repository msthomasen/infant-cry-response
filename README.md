# **No evidence that women are more reactive to infant crying than men: two laboratory studies in non-parents**

This repository contains data, code, model files, fitted model objects, figures, and supplementary analysis materials for: **No evidence that women are more reactive to infant crying than men: two laboratory studies in non-parents**.



### **Overview**

This project examined whether women and men differ in their behavioural responses to infant crying in two laboratory studies with non-parents.



In **Study 1**, mixed-gender dyads completed a matrix task while occasionally hearing infant cries. Either participant could stop the sound by pressing a button. Analyses examined whether female participants were more likely than male participants to press the button, how responding developed across successive sound events within dyads, and whether individual and dyadic response patterns were associated with subsequent cooperation in a repeated Prisoner's Dilemma task.



In **Study 2**, participants completed the matrix task while occasionally hearing both infant cries and alarm sounds. Analyses examined overall gender differences in task performance and whether sound exposure affected answered-round duration differently for female and male participants.



Both studies also included supplementary analyses of Gender Equality Scale (GES) scores and hearing-test performance.



### **Data availability**

The data used in the analyses are included in this repository.



The data/ folder contains the original source files required to construct the analysis datasets. These include data exported from the experimental task, sound-response data, round-level and second-to-second task data, and hearing-test files.



The data/cleaned\_data/ folder contains analysis-ready datasets generated by 00\_clean\_data.Rmd. These files are used in the Study 1 and Study 2 analysis scripts.



The cleaned datasets are:

* **demographics.csv**: participant demographics, study setup, exclusion status and participant-level hearing summaries.
* **dyad\_info.csv**: Study 1 dyad-level mapping of participants, gender, position, age, and exclusion status.
* **ges\_long\_clean.csv**: item-level Gender Equality Scale data.
* **ges\_summary.csv**: participant-level Gender Equality Scale summary scores.
* **hearing\_clean.csv**: participant-level hearing-test summaries.
* **hearing\_trials\_clean.csv**: cleaned trial-level hearing-test data.
* **prisoner\_dilemma\_clean.csv**: Study 1 Prisoner's Dilemma decisions and payoffs in long format.
* **roundwise\_clean.csv**: participant-by-round matrix task data with sound exposure and button press information.
* **sound\_events.csv**: sound event level data containing sound timing and button press responses.

### **Study 1: Dyadic button-press task**

#### ***Study overview***

Study 1 examined behavioural responding to infant crying in mixed-gender dyads. Participants completed a matrix solving task individually, but in the same room, while occasionally hearing infant cry sounds. Whenever the cry was playing either participant could press a button within arm's reach to stop the sound.

The primary analyses examined whether button presses were more likely to be made by the female than by male participant and whether responding showed stable dyad-specific sequential patterns. Additional analyses examined task performance, cooperation in a subsequent repeated Prisoner's Dilemma task, dyads in which neither participant pressed the button during any sound events, GES scores, and hearing-test performance.



#### ***Key findings***



1. There was no evidence for an overall population-level female bias in button pressing. The estimated population-level probability that a press was made by the female participant was close to 0.50, with evidence favoring the null hypothesis of no overall gender bias.
2. Button-press behavior varied substantially across dyads. Sequential analyses showed persistence in responding, such that no-press, a male-press, and a female-press were each most likely to be followed by the same response.
3. Prior-sensitivity analyses indicated that the conclusions from both the hierarchical Beta-Bernoulli and first-order Markov models were robust to the alternative prior and pooling specifications examined.
4. Additional analyses of initial cooperation in the Prisoner's Dilemma showed no association between earlier button-press behavior and initial decisions made in the Prisoner's Dilemma.
5. A subgroup of 11 dyads in which neither participant pressed the button at either of the sound events emerged during the data collection. #### ***Analyses scripts***



* **s1\_01\_sample\_description.Rmd**: Study 1 sample characteristics, exclusions, and demographic summaries.
* **s1\_02\_descriptive\_results.Rmd**: button-press descriptives, participant-level task-performance descriptives, paired gender comparisons of task performance, and associated assumption checks.
* **s1\_03\_buttonpress\_bernoulli.Rmd**: hierarchical Beta-Bernoulli model of responder gender conditional on a button press, Bayes factor calculation, model diagnostics, dyad-level estimates, and prior-posterior visualisations.
* **s1\_04\_buttonpress\_markov.Rmd**: hierarchical first-order Markov model of successive no-press, male-press, and female-press state, population- and dyad-level transition summaries, persistence comparisons, model diagnostics, and visualisations.
* **s1\_05\_prisoners\_dilemma.Rmd**: descriptive analysis of cooperation in the repeated Prisoner's Dilemma and Bayesian logistic modelling of whether earlier button-press behavior predicted initial cooperation.
* **s1\_06\_no\_press\_dyads\_analysis.Rmd**: analysis of dyads in witch neither participant pressed during any sound event, including participant-level task-performance comparisons and a mixed-effects model of answered-round duration during infant-cry versus no-sound rounds.
* **s1\_07\_prior\_sensitivity\_testing.Rmd**: sensitivity analyses for the hierarchical Beta-Bernoulli and hierarchical first-order Markov models under alternative population-level priors and pooling specifications.
* **s1\_GES\_analysis.Rmd**: Study 1 Gender Equality Scale descriptives, paired gender comparison, assumption assessment, and internal consistency analysis.
* **s1\_hearing\_analysis.Rmd**: Study 1 hearing-test descriptives and Bayesian analyses of overall and frequency-specific gender differences in hearing thresholds.



#### ***Statistical approach***

The primary button-press analysis used a **hierarchical Beta-Bernoulli model** in which the probability that a button press was made by the female participant was allowed to vary across dyads. Population-level gender bias was assessed from the posterior distribution of the population mean female-press probability, with Savage-Dickey Bayes factors used to quantify evidence for or against an equal female/male press probability.



Sequential dependence in button-press behavior was examined using a **hierarchical first-order Markov model** with three response states: no press, male press and female press. Population-level transition probabilities were partially pooled across dyads, while dyad-specific transition matrices captured between-dyad variation in response patterns.



The Prisoner's Dilemma analysis used a **Bayesian logistic model** to examine whether the dyads total press count and participants' relative press count were associated with cooperation on the first Prisoner's Dilemma round. A dyad-level random effect accounted for dependence between partners.



Participant-level task-performance differences between female and male participants in Study 1 was assessed using **paired-samples t-tests**. Assumptions were assessed using within-dyad difference-score boxplots, Q-Q plots, and Shapiro-Wilk tests.



For the subset of dyads in which neither participant pressed the button, answered-round duration was analysed using a **linear mixed-effects model** fitted to log-transformed round duration. The model included sound condition, gender, and their interaction, with random intercepts for both participants and dyads. Estimated marginal means and contrasts were obtained using emmeans.



Study 1 GES scores were compared between the female and male participants using a **paired-samples t-test**. Hearing thresholds were examined using **Bayesian models** that accounted for censored trials, with separate models for overall gender difference and frequency-specific gender differences.



Prior-sensitivity analyses examined whether conclusions from the hierarchical Beta-Bernoulli and Markov models changed under alternative prior distributions and different levels of hierarchical pooling.



### **Study 2: Individual matrix task**

#### ***Study overview***

Study 2 examined whether female and male participants differed in individual task performance and behavioural responses to infant crying when there was no opportunity to stop the sound.



Participants completed the matrix task while occasionally hearing infant cries or alarm sounds. Analyses first compared overall participant-level task performance between female and male participants and then examined whether answered-round duration differed across round conditions and whether these effects differed by gender.



GES scores and hearing-test performance were also examined.



#### ***Key findings***



1. There was no clear evidence for overall gender differences in the number of matrices seen, answered, or correctly solved, as well as in participants' mean round duration.
2. Sound exposure, both infant-cries and alarm sounds, was associated with longer answered-round durations relative to no-sound rounds, but there was no evidence that the effects of infant cries or alarm sounds on round duration differed by gender.
3. Together with the results of Study 1, these results do not support the hypothesis that women are more reactive than men to infant crying in these laboratory tasks.



#### ***Analyses scripts***



* **s2\_01\_sample\_description.Rmd**: Study 2 sample characteristics, exclusions, sound-exposure descriptives, and participant-level task-performance summaries.
* **s2\_02\_participant\_performance\_analysis.Rmd**: participant-level gender comparisons of matrices seen, answered, and correctly solved and mean round duration, together with boxplots, Q-Q plots, and Shapiro-Wilk assumption checks.
* **s2\_03\_sound\_effect\_analysis.Rmd**: linear mixed-effects analysis of answered-round duration across no-sound, alarm , and infant-cry rounds, estimated marginal means and contrasts, model diagnostics, and visualisations.
* **s2\_GES\_analysis.Rmd**: Study 2 GES descriptives, Bayesian gender comparison, prior-posterior assessment, and internal-consistency analysis.
* **s2\_hearing\_analysis.Rmd**: Study 2 hearing-test descriptives and Bayesian analyses of overall and frequency-specific gender differences in hearing threshold.



#### ***Statistical approach***



Overall gender differences in Study 2 task performance were examined using **Welch's independent-samples t-tests** for the total numbers of matrices seen, answered, and correctly solved and participants' mean round duration. Distributional assumptions were assessed separately by gender using boxplots, Q-Q plots, and Shapiro-Wilk tests.



Sound effects on answered-round duration were analysed using a **linear mixed-effects model** fitted to log-transformed round duration. Fixed effects included sound condition, gender, and their interaction, with a random intercept for participant. Estimated marginal means were used to compare alarm versus no sound, infant cry versus no sound, and alarm versus infant cry within each gender, as well as to assess whether these contrasts differed between female and male participants. Multiplicity-adjusted inference used the Holm method.



Study 2 GES scores were compared between female and male participants using a **Bayesian independent-groups t-test**. Hearing thresholds were analysed using the same Bayesian approach as in Study 1.



### **Model files and saved results**



Bayesian models were fitted using Just Another Gibbs Sampler (JAGS) through the R2jags package. The .bugs files in models/ contain the JAGS model specifications used for the main analyses, while models/prior\_sensitivity\_test/ contains the alternative model specifications used in the Study 1 prior-sensitivity analyses.



Previously fitted Bayesian model objects are supplied as .rds files in the corresponding study\_1/results/ and study\_2/results/ folders. The analysis scripts first check for these saved objects and load them when available. If a required fitted object is not present, the corresponding JAGS model is fitted and the results are saved automatically.



The simulated\_priors/ folder contains saved prior-simulation objects used to generate the prior-hierarchy and prior-sensitivity visualisations.

### **Usage**



1. Clone or download this repository
2. Set the R working directory to the repository root
3. *Optional*: Run 00\_clean\_data.Rmd to reconstruct the files in data/cleaned\_data/
4. Run the Study 1 scripts from study\_1/code. The numbered scripts (s1\_01 to s1\_07) should be run in numerical order. *s1\_GES\_analysis.Rmd* and *s1\_hearing\_analysis.Rmd* can be run independently at any point.
5. Run the Study 2 scripts from study\_2/code. The numbered scripts (s2\_01 to s2\_03) should be run in numerical order. *s2\_GES\_analysis.Rmd* and *s2\_hearing\_analysis.Rmd* can be run independently at any point.



The supplied .rds files contain the Bayesian model fits used for the reported analyses. Therefore, it is not necessary to refit the JAGS models to reproduce the reported summaries and figures. If the saved fitted objects are removed or unavailable, the relevant scripts will refit the models from the supplied data and .bugs specifications.



**Note:** JAGS model fitting can be time consuming, particularly for the hierarchical button-press models and prior-sensitivity analyses.
